# White Liquid Glass UI studies

Offline SwiftUI iOS 26 design sample. Ten home screen layouts use only native SwiftUI controls, SF Symbols, system typography and Liquid Glass button/navigation materials.

All names and numeric values are presentation fixtures. There are no account credentials, production endpoints, databases, backend sources or transaction execution logic. No production application history is included.

Build with Xcode 26+, XcodeGen and an iOS 26 simulator. The workflow uses a standard macOS runner to build an unsigned simulator sample and export screenshots. No device provisioning is needed.
